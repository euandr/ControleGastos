# Notas

## biblioteca: SQLAlchemy

SQLAlchemy é uma biblioteca de mapeamento objeto-relacional (ORM) para Python, que facilita a interação com bancos de dados relacionais.
Utilizando ela posso trabalhar com O banco de dados sem usar SQL diretamente, mas sim através de objetos Python.

## Biblioteca: Pydantic

Pydantic é uma biblioteca de validação de dados e gerenciamento de configurações para Python.
Como o Supabase atua como altenticador, o Pydantic pode ser mais uma camada de seguranca.
